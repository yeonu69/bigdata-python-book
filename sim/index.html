웹 시뮬레이터

『AI 격변 시대, 데이터에게 묻다 — 빅데이터분석 with 파이썬』 각 장 04절의 [시뮬레이터로 해 보기] 페이지입니다. 설치 없이 웹 브라우저에서 개념을 직접 움직여 봅니다. 실습 노트북과 데이터는 깃허브 저장소에 있습니다.

1장 빅데이터 첫걸음 시뮬레이터 우리는 이미 빅데이터 속에 산다: 빅데이터와 데이터 분석 웹 브라우저에서 0이 섞인 평균과 중앙값, %와 %p, 큰 수의 어림셈과 단위 계단, 한 행의 단위(시간·하루·시각·평일과 주말)를 직접 움직여 봅니다. 책의 따릉이 1년 기록(8,760시간, 6,172,314건)으로 계산한 값이 들어 있습니다. 2장 넘파이 배열 시뮬레이터 숫자를 한꺼번에: 파이썬과 넘파이 서울 따릉이 8,760시간 실제 기록으로 reshape 접기, axis 방향 계산, 마스크로 고르기, 내적·브로드캐스팅·표준화를 손으로 움직여 봅니다. 인터넷 없이 열리는 HTML 파일 하나. 3장 데이터 정제 시뮬레이터 지저분한 데이터 정리하기: 판다스와 데이터 정제 웹 브라우저에서 날짜 형식 읽기, 0과 결측값 채우기, 중앙값과 IQR 울타리로 튀는 값 찾기, 공휴일 표 합치기를 직접 움직여 봅니다. 책의 따릉이 데이터로 계산한 값이 들어 있습니다. 4장 탐색적 분석·시각화 시뮬레이터 그림으로 데이터와 대화하기: 탐색적 분석과 시각화 웹 브라우저에서 히스토그램의 칸 수와 로그 눈금, 상자 그림의 울타리, z점수와 상관계수(점 끌기), 잘린 축의 거짓말 계수와 나누어 그리기를 직접 움직여 봅니다. 책의 따릉이 데이터(운영 8,465시간, 352일)가 들어 있습니다. 5장 통계적 추론 시뮬레이터 우연인가 아닌가: 통계적 추론 웹 브라우저에서 표본과 표준오차, 이름표 섞기(순열검정)와 웰치 t검정, 신뢰구간 그물, 다중검정과 효과 크기를 직접 움직여 봅니다. 책과 같은 따릉이 데이터(운영 8,465시간, 352일)로 계산한 값이 들어 있습니다. 6장 데이터 불러오기 시뮬레이터 파일에서, 웹에서: 데이터 불러오기 웹 브라우저에서 인코딩(글자와 바이트), 파일 크기와 읽는 시간 어림하기, 엑셀 12개 합치기와 행 수 검산·24시 바꾸기, 연습 사이트를 예의 바르게 돌며 모으기를 직접 움직여 봅니다. 책의 에어코리아 2025년 엑셀과 연습 사이트 숫자가 들어 있습니다. 7장 군집화 시뮬레이터 끼리끼리 모으기: 군집화 웹 브라우저에서 거리와 표준화, k-평균의 배정과 갱신, 엘보우와 실루엣, 지진 세 유형 나누기를 직접 움직여 봅니다. 책의 지진 데이터에서 뽑은 1,500건과 책의 숫자가 들어 있습니다. 8장 회귀분석 시뮬레이터 내일의 발전량: 회귀 분석 웹 브라우저에서 점을 찍으면 회귀식, 회귀선, SSE, R²가 바로 계산됩니다. 다중회귀와 다중공선성, 경사하강법, 평균으로의 회귀 탭도 있습니다. 9장 분류분석 시뮬레이터 스팸일까, 아닐까: 분류 웹 브라우저에서 시그모이드, 문턱값과 혼동행렬(ROC·PR 곡선), 베이즈와 나이브 베이즈, 결정 경계와 규제를 직접 움직여 봅니다. 책의 스팸 문자 데이터로 계산한 값이 들어 있습니다. 10장 트리·앙상블 시뮬레이터 스무고개와 집단지성: 결정나무와 앙상블 웹 브라우저에서 지니 불순도와 첫 질문, 깊이와 과적합, 다수결과 숲(상관 ρ), 부스팅의 잔차와 학습률을 직접 움직여 봅니다. 책의 은행 기록으로 계산한 값이 들어 있습니다. 11장 텍스트 분석 시뮬레이터 리뷰 속 마음 읽기: 텍스트 분석 웹 브라우저에서 TF-IDF 계산, 코사인 유사도, 로지스틱 회귀의 조각 점수 합, 확신과 망설임(사람에게 넘길 구간)을 직접 움직여 봅니다. 책의 영화 리뷰 모델(시험 정확도 87.1%)로 계산한 값이 들어 있습니다. 12장 시계열 시뮬레이터 작년 이맘때처럼: 시계열 분석 웹 브라우저에서 이동평균과 계절 지수, 자기상관과 차분, 지수평활, 기준선 겨루기와 오차(MAE·MAPE)를 직접 움직여 봅니다. 책의 항공 승객과 한국 전력 데이터로 계산한 값이 들어 있습니다. 13장 피지컬 AI 시뮬레이터 몸을 가진 AI: 센서 데이터로 읽는 피지컬 AI 웹 브라우저에서 샘플링과 FFT, 중력과 기울기, 사람 단위로 나누기(데이터 누수), 출력과 고장을 직접 움직여 봅니다. 책의 동작 인식(HAR)·공장 기계(AI4I) 데이터로 계산한 값이 들어 있습니다.

# AI 격변 시대, 데이터에게 묻다 — 빅데이터분석 with 파이썬

*실전 데이터로 배우는 데이터 분석의 개념부터 모델까지* (길벗캠퍼스)

이 저장소에는 책의 장별 **실습 노트북(예제 코드)** 과 **실습 데이터**가 들어 있습니다. 모든 실습은 구글 코랩(Colab)에서 웹 브라우저만으로 돌릴 수 있습니다.

## 시작하는 법

1. 아래 표에서 장의 **Colab에서 열기** 단추를 누릅니다(구글 계정이 필요합니다).
2. 코랩 위쪽 메뉴의 **런타임 → 모두 실행**을 누르거나, 위에서부터 한 셀씩 `Shift + Enter`로 실행합니다.
3. 첫 셀은 한글 글꼴 등 필요한 라이브러리를 설치하고, 이어지는 **데이터 받기** 셀이 그 장의 데이터를 이 저장소에서 내려받습니다.

내 컴퓨터에서 돌리려면 저장소를 내려받은 뒤(초록색 **Code → Download ZIP**) 주피터 노트북으로 여십시오.

## 데이터 출처와 이용 조건

- **한국 공공데이터** (한국전력거래소, 서울교통공사, 기상청 기상자료개방포털, 에어코리아): 공공데이터포털(data.go.kr) 등에서 받은 원자료를 실습용 UTF-8 CSV로 정리해 `data/` 폴더에 넣었습니다. 공공누리 제1유형(출처 표시) 조건에 따라 출처를 밝혀 재배포합니다.
- **해외 공개 데이터** (UCI 머신러닝 저장소, 네이버 영화 리뷰 NSMC, USGS 지진, Open Power System Data 등): 저장소에 복사하지 않고, 노트북이 원래 공개 주소(깃허브 사본)에서 바로 읽습니다. 주소와 출처는 각 장 README에 있습니다. 각 데이터의 이용 조건은 원 출처를 따릅니다(UCI 데이터는 대부분 CC BY 4.0, NSMC는 CC0).
- 선택 실습(☆)에서 원자료를 직접 받아 합치는 과정은 독자가 해 보는 실습이라, 그 원자료는 넣지 않았습니다.
